# Sitio de Lhambda

Sitio web de Lhambda: React, React Router, Framer Motion y Tailwind CSS. Se publica solo en GitHub Pages con cada cambio en `main`.

```
npm install
npm run dev      # verlo mientras se edita
npm run build    # genera dist/
```

- Todo el texto del sitio está en `src/data/contenido.jsx`.
- Las páginas están en `src/pages` y los efectos en `src/components/fx.jsx` y `visuals.jsx`.
